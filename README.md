# hanumoka.github.io

[https://hanumoka.github.io](https://hanumoka.github.io) — 개인 사이트.

## 지금 상태

**정적 사이트 생성기를 아직 고르지 않았습니다.** 지금은 빌드 도구 없이 `index.html`
하나를 브랜치 루트에서 그대로 서빙합니다. GitHub Pages 배포가 동작하는지 확인하기
위한 최소 구성입니다.

생성기 후보는 **Astro**(공식 GitHub Pages Action이 있고 JS를 기본 0으로 전송)와
**Jekyll**(GitHub이 서버에서 직접 빌드해 Actions가 필요 없음)입니다. 이 저장소의
이전 판이 쓰던 **Gatsby는 후보에서 제외했습니다** — 2023년 Netlify 인수 이후
코어 팀이 이탈했고 플러그인 생태계가 대부분 방치됐습니다.

## 구성

| | |
|---|---|
| 형태 | User site (저장소 이름이 계정명과 일치해야 함) |
| 배포 | `main` 브랜치 루트 |
| 빌드 | 없음 |

`.nojekyll`을 두어 Jekyll 처리를 끕니다. 밑줄로 시작하는 디렉터리가 조용히
무시되는 것을 막기 위해서입니다.

## 콘텐츠는 어디서 오는가

**글의 정본은 이 저장소가 아닙니다.** 별도의 비공개 문서 허브에서 관리하고,
그중 공개할 것만 골라 이곳으로 산출합니다. 이 저장소는 파생물만 갖습니다.

산출 경로는 아직 만들지 않았습니다.
