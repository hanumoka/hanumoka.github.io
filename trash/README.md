# 초안 휴지통

소유자: hanumoka. 마지막 검토: 2026-10-04.

기존 초안과 글별 자산을 원래 내용 그대로 보관한다. 이 폴더는 Astro 콘텐츠와
`public/` 밖에 있어 사이트 페이지·검색·RSS·사이트맵에 포함되지 않는다.
공개 Git 저장소에 커밋하면 저장소 파일은 누구나 읽을 수 있다.

`manifest.json`은 이동일, 원래 경로, 보관 경로와 파일별 SHA-256을 기록한다.
본문의 `draft: true`와 기존 `key`는 바꾸지 않는다. 휴지통 파일은 포맷터에서도 제외한다.

## 복구

1. 작업 트리를 확인하고 복구하려는 글의 `key`와 원래 폴더가 현재 글과 겹치지 않는지 확인한다.
2. `restoreWith`에 적힌 글이 현재 콘텐츠에 있는지 먼저 확인한다. 없다면 함께 복구한다. manifest의 `archived` 폴더를 `original` 위치로 옮긴다. MDX가 참조하는 공통 컴포넌트도 확인한다.
3. 복구한 글은 `draft: true`를 유지하고 manifest에서 그 항목을 제거한다.
4. `npm run build`와 `npm run check:dist`를 실행해 초안 목록·본문·자산을 확인한다.

경로 충돌이나 빌드 오류가 있으면 기존 파일을 덮어쓰지 않는다. 복구한 폴더를
원래 휴지통 경로로 되돌리고 원인을 확인한다. 소유자가 검토하기 전에는 정식 글로 전환하지 않는다.

`saas-gpu-llm-ops`와 `temporal-basics`는 기존 공개 이력에 있던 회사 운영 경험의 공개 적합성을 소유자가 판정하기 전까지 복구하지 않는다. 보관 폴더 이동은 과거 Git 이력을 비공개로 만들지 않는다.
